# Evaluating Pragmatic Reasoning in Large Language Models: Evidence from Scalar Diversity

Evaluating pragmatic reasoning in large language models (LLMs) remains challenging because model behavior can vary depending on evaluation method. Previous studies suggest that prompt-based judgments may diverge from models’ internal probability distributions, raising questions about whether observed performance reflects underlying competence or task-induced behavior. This study examines this issue through scalar implicature, using scalar diversity as a graded diagnostic for pragmatic inference. Following Hu and Levy (2023), this study compares direct probability measurement and metalinguistic prompting across multiple models and experimental settings. The results show that neither evaluation method consistently outperforms the other and that pragmatic behavior varies across model families and task structures. These findings highlight the importance of evaluation design when interpreting pragmatic abilities in LLMs.
